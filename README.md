# 🎓 Student Performance Prediction

## 📌 Project Description

Student Performance Prediction is a Machine Learning-based web application that predicts a student's final score using academic details.

## 🎯 Objective

The objective of this project is to predict student performance based on study hours, attendance, previous marks, and assignment marks.

## 🛠️ Technologies Used

- Python
- Machine Learning
- Scikit-learn
- Pandas
- Streamlit
- Linear Regression

## ✨ Features

- Enter study hours
- Enter attendance percentage
- Enter previous exam marks
- Enter assignment marks
- Predict final score
- Display student performance level

## ⚙️ How It Works

1. Student details are entered.
2. The data is given to the Machine Learning model.
3. Linear Regression processes the input.
4. The final score is predicted.
5. The system displays the performance level.
